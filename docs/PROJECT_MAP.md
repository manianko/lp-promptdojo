## 1. プロダクト定義（1行）

日本語ネイティブ品質・月980円・実技添削つきの、Duolingo型AI活用学習アプリ。
売り物は「情報」ではなく **摩擦の除去（1回3〜5分）× 継続装置（ストリーク/XP/実績）× 実技フィードバック（LLM採点）**。

## 3. 競合ポジション（要点のみ）

- **Coursiv（海外・日本進出済）**：需要実証者。弱点＝機械翻訳品質の日本語 / $30〜40月 / 不透明な自動更新 / 演習不足の不満
- **国内AIスクール（SHIFT AI等）**：高額・セミナー営業型。低単価アプリ形態は不在
- **無料コンテンツ（YouTube/note）**：最大の競合。「情報」では戦わない
- 勝ち筋：**ネイティブ日本語 × 明朗会計 × 実技特化 × 良心価格**

## 4. フェーズ構成

```
Phase 1: 需要検証LP（← いまここ）
  └ リポジトリ: lp-promptdojo（Astro + Tailwind + TS、既存LP資産の流儀を踏襲）
  └ 成果物: ウェイトリストLP公開 + 広告少額テスト + 判定
Phase 2: MVP開発（判定クリア後）
  └ リポジトリ: app-promptdojo（React + TS PWA / Node / Supabase / Stripe）
  └ 成果物: Lv1全レッスン + 実技採点 + ストリーク/XP + 課金
Phase 3: βテスト（ウェイトリスト招待）→ 正式リリース
Phase 4: B2Bトリガー監視 → 法人プラン（管理画面・席数課金・請求書払い）
```

### B2B起動トリガー（いずれか成立でPhase 4検討開始）
- 同一企業ドメインからの複数登録を検知
- 問い合わせに「会社で/チームで使いたい」が到来
- 有料ユーザーが数百人規模に到達

## 5. 技術スタック（決定済み）

| 層 | 選定 | 備考 |
|----|------|------|
| 検証LP | Astro + Tailwind + TypeScript | 既存LPの流儀を踏襲（config.ts単一真実源 等） |
| アプリ本体 | React + TypeScript（PWA） | Phase 2 |
| バックエンド | Node + Supabase（Auth / Postgres / 学習ログ） | organizationテーブルは最初からスキーマのみ用意 |
| LLM採点 | 安価モデル（Haiku級）+ ルーブリックJSON出力 | 原価目標: 1採点 1円未満 |
| 決済 | Stripe | 個人サブスク→将来の法人請求書払いまで同基盤 |
| ホスティング | Vercel | 既存LPと同運用 |
| 計測 | GA4（+ 広告媒体タグ） | 既存LPと同運用 |
