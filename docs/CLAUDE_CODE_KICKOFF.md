## 貼り付け用プロンプト

```
このディレクトリで新規LPプロジェクトを立ち上げます。作業前に必ず以下を読んでください：
- docs/PROJECT_MAP.md（全体戦略）
- docs/LP_SPEC.md（LP要件・コピー・コンプラ規律・config構成）
- docs/TASKS.md（タスクリスト。あなたの担当は [CC] タグ）

【今回のセッションでやること（TASKS.md 1-B）】
1. Astro + Tailwind + TypeScript でプロジェクトを初期化する（このフォルダ直下）
2. src/config.ts を LP_SPEC.md §7 の構成どおり作成（ダミー値のまま。本物っぽい値を創作しない）
3. リポジトリ直下に CLAUDE.md を作成し、以下を記載する：
   - 作業規律：現物を読む→判断メモ→編集→npm run dev確認→報告してOK待ち→CLAUDE.md更新、のサイクル厳守
   - コンプラ規律：LP_SPEC.md §3 の要約（成果断定禁止/料金は予定表記/実績創作禁止/競合名指し禁止）
   - 進捗セクション：TASKS.md 1-B/1-C の項目をコピーして状態管理
4. npm run dev が起動することを確認して報告

【守ること】
- セクション実装（1-C）は今回やらない。scaffold完了の報告とブラウザ確認OKを待ってから、
  1セクションずつ進める（複数ファイル同時変更禁止）
- 構成・命名は docs/ の記載を真実源とし、勝手に変えない。変えたい場合は提案として報告
- 各 .astro ファイル冒頭に設計意図コメントを1行残す
- 作業終了時に TASKS.md のチェックボックスと CLAUDE.md の進捗を更新
```
